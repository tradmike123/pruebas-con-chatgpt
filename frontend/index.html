🔍 Wizard — Chequeo único de PC para POV

Pulsa “CHEQUEAR MI PC” y recibe un diagnóstico claro de si tu equipo está listo para producir videos POV con herramientas gratuitas. Si algo falta, verás exactamente qué y cómo resolverlo paso a paso.

⚙️ Cómo ejecutar el chequeo completo con script local

Para validar permisos, espacio en disco, GPU y detectar versiones portables automáticamente, ejecuta el script correspondiente y vuelve a pulsar REINTENTAR CHEQUEO.

Windows (PowerShell)

New-Item -Path C:\proyectos_pov -ItemType Directory -Force | Out-Null
New-Item -Path C:\proyectos_pov\herramientas -ItemType Directory -Force | Out-Null
Invoke-Expression @'
Get-ComputerInfo | Select-Object OsName, OsVersion, OsArchitecture
(Get-CimInstance Win32_Processor).NumberOfCores | Measure-Object -Sum
[math]::Round(((Get-CimInstance Win32_OperatingSystem).TotalVisibleMemorySize/1MB),2)
[math]::Round(((Get-PSDrive -Name C).Free/1GB),2)
([bool]([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole] "Administrator"))
dxdiag /t $env:TEMP\dxdiag.txt
where ffmpeg
Test-Path "C:\proyectos_pov\herramientas\ffmpeg\win64\ffmpeg.exe"
'@

macOS

mkdir -p ~/proyectos_pov/herramientas
sw_vers && uname -m
sysctl -n hw.physicalcpu
vm_stat | awk '/free/ {printf "%.2f\n", ($3*4096)/1073741824 }'
df -h ~ | tail -1
which ffmpeg
test -x ~/proyectos_pov/herramientas/ffmpeg/macos/ffmpeg

Linux

mkdir -p ~/proyectos_pov/herramientas
cat /etc/os-release && uname -m
nproc
free -g
df -h ~ | tail -1
which ffmpeg
test -x ~/proyectos_pov/herramientas/ffmpeg/linux/ffmpeg

Nota: los navegadores no pueden acceder a la lista completa de programas instalados ni a privilegios de administrador. Por eso el script local es necesario para el chequeo 100% real.
